Only used where recording falls back to the browser's own MediaRecorder — Firefox, and anything else without the WebCodecs pieces this app needs. Normally ignored in Chrome and Edge, which encode through WebCodecs, but they use it too if no WebCodecs configuration works.

Chrome and Edge only. Hardware H.264 encodes 4K without dropping frames; the software codecs trade that for smaller uploads. If the codec you pick isn't available here, the recorder falls back and says which one it used — H.264 itself falls back to a software H.264 encoder, which is slower and no smaller. For Safari viewers, H.264 also needs a recording machine with an AAC encoder: without one (desktop Linux) the MP4 carries Opus audio, which Safari cannot play.
